# Security policy

## Reporting a vulnerability

Email security@amodb.dev with a description of the problem and steps to reproduce it.

Please do not open a public issue for security reports. Never include a live API key in a report. If a key was exposed, revoke it in your account at https://amodb.dev and create a new one.

## Response time

We reply to every report within 72 hours.

## Supported versions

Only the latest release receives security fixes.
